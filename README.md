# Carrot Street Puzzle

Оригинальная Android-игра в жанре пошаговой головоломки на клеточном поле: игрок собирает морковки, объезжает автомобили и проходит уровни. Игра сделана с нуля и не использует название, персонажей, графику или код Bobby Carrot.

## Что уже есть
- Android only
- сенсорное управление свайпами и экранными кнопками
- несколько уровней с процедурной раскладкой
- морковки, препятствия и машины
- очки и переход на следующий уровень
- портретный режим
- без рекламы и без обязательного интернета
- готовый package name: `com.example.carrotstreetpuzzle`

## Сборка
Откройте папку в Android Studio и выполните Build > Generate Signed Bundle / APK. Для Google Play нужен подписанный Android App Bundle (`.aab`).

## Платная публикация
В Play Console в разделе цен можно выставить приложение как платное и указать цену. Google также применяет комиссию к продажам. Текущие правила и ставки зависят от страны и программы разработчика.

Перед публикацией нужно подготовить название, описание, иконку, скриншоты, возрастной рейтинг, privacy/data safety и подписанный release bundle.
